# MedEfix Roadmap

## Phase 1 – MVP (Revenue-first)
### Patient App
- Login / Signup (OTP, Email)
- Location-based service discovery
- Medicine search + upload prescription
- Doctor/Clinic slot booking
- Lab test booking
- Dental booking
- Ambulance booking (basic)
- Online payment (UPI, Cards)
- Order & booking history
- Push notifications

### Provider Panel
- Profile & service management
- Slot/time management
- Order/booking acceptance
- Status updates (Confirmed → Completed)
- Basic earnings report

### Admin Panel
- User & provider management
- Service category management
- Commission setup
- Order/booking monitoring
- Manual dispute handling
